# Data provenance and terms

The repository software license does not relicense third-party source material.

- Tourism scoring rows are derived from the tourism corpus already used in this
  repository and the authors' recorded question/evidence workflow. Source text
  remains subject to its source terms. The row grades are a frozen development
  analysis input, not a completed independently blinded benchmark. No blanket
  public redistribution license for the full scraped corpus is asserted here.
- Original reviewer workbooks, identities, free-text review notes and complete
  historical training/validation/TEST pair files are not redistributed by this
  change. Their content hashes and the earlier source audit are retained.
- WikiQA native data and the modified evaluation representation retain the
  **Microsoft Research Data License Agreement** in
  `wikiqa/WIKIQA_LICENSE_AND_MODIFICATIONS.md`. That file includes original
  terms, source attribution and the dated 12 November 2026 modification notice.
  The dataset is not relicensed under the project's software license.
- Checkpoint metadata and SHA-256 values identify existing artifacts. No model
  weights or claim of a newly trained or newly licensed model is included.
